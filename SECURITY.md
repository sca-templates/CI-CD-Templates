# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities through the [GitHub Security Advisory](https://github.com/sca-templates/CI-CD-Templates/security/advisories/new) using the **"Report a vulnerability"** form.

You should receive a response acknowledging the report within 3 business days, and an assessment of the issue within 10 business days after the first response.

Do **not** open a public issue or pull request for any security concern.

## What to include

When filing a report, please include as much detail as possible:

- The type of issue (e.g. command injection, secret leakage, misconfigured permissions).
- Which workflow, action, or ruleset is affected and a path to the file.
- A description of the impact and a proof of concept if available.
- Suggested fix, if you have one.

## Supported versions

Only the default branch (`main`) is actively maintained. Security fixes are
landed on `main` and released through the CI/CD-Templates release flow.
